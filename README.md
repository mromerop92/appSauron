FASE 2: FrontEnd (Simulación de la App SAURON)
Queremos que el operador de planta pueda introducir datos de forma sencilla. Utilizando HTML, CSS y JavaScript 
(puedes usar Javascript puro o un framework como React, Vue o Angular, lo que prefieras),
crea una pequeña interfaz web (una sola página) que contenga:
1.	Un formulario sencillo para que el operador introduzca un nuevo registro manual: Máquina (desplegable),
    Lote, Cantidad de Scrap y Motivo.
2.	Un gráfico dinámico (puedes usar librerías como Chart.js, ECharts, etc.)
  	que muestre una simulación visual de la tasa de scrap de la última semana. Nota: No necesitas conectarlo a una base de datos real;
  	utiliza datos "mockeados" (ficticios) en un archivo JSON o directamente en el código.
